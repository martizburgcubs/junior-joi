JUNIOR JOI LIVE WEBSITE

1. Open js/config.js.
2. Paste your Supabase Project URL.
3. Paste your Supabase publishable key or anon public key.
4. Never use the service_role key.
5. Public website: index.html
6. Admin dashboard: admin.html
7. Upload the full folder to GitHub or Netlify.

IMPORTANT:
Standings currently use:
- Win = 2 points
- Loss = 1 point
- Tiebreak: log points, points difference, points scored

Confirm the official tournament rules before the event.
